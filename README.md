# Favoreto Attendance Pro

Crie um aplicativo de controle de presença para a Favoreto Brazilian Jiu-Jitsu, com três unidades: Brickell, Coconut Grove e Hialeah. O aplicativo deve permitir cadastro de alunos adultos e crianças, check-in por QR Code, calendário de aulas, controle de presença, relatórios por unidade e horário, histórico individual de frequência e alertas de ausência. Inclua um painel administrativo que mostre quais aulas estão cheias, quais têm baixa frequência e quais horários têm demanda para abrir novas turmas. Professores devem visualizar somente os dados necessários para suas aulas, e responsáveis devem acessar apenas os dados de seus filhos. O aplicativo deve funcionar em celulares e computadores, em inglês, português e espanhol, com identidade visual personalizável.
